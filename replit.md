# Goal Bingo Tracker

## Overview

Goal Bingo Tracker is a personal productivity web application that allows users to create customizable bingo cards for tracking their goals. Users can create 5x5 bingo grids with custom text, mark tiles as completed, and personalize their boards with colors, images, and completion markers. The app supports sharing boards via unique URLs and exporting boards as images.

## System Architecture

### Frontend Architecture

**Framework & Build System:**
- React 18 with TypeScript for type-safe component development
- Vite as the build tool and development server for fast HMR and optimized production builds
- Wouter for lightweight client-side routing (Home page, View Card page, Monetization page, 404)

**UI Component System:**
- shadcn/ui component library built on Radix UI primitives
- "New York" style variant configured with neutral base color
- Tailwind CSS for utility-first styling with custom design tokens
- Design system emphasizes touch-first interactions with minimum 60px tap targets on mobile
- Typography uses DM Sans/Inter from Google Fonts for clean, modern readability

**State Management:**
- TanStack Query (React Query) for server state management and caching
- Local React state for UI interactions and optimistic updates
- Custom event system for tile image updates from customization panel
- No global state management library - component-level state is sufficient for this application's scope

**Key Features:**
- **Bingo Grid Component**: 5x5 grid with editable tiles that support click-to-complete interactions
- **Customization Panel**: Collapsible sections for colors, images, markers, typography, board layout, and deadline timer
- **Image Upload**: Client-side image handling with FileReader API (2MB limit, converted to base64)
- **Export Functionality**: Uses html-to-image library to convert grid to downloadable PNG
- **Theme Toggle**: Light/dark mode with localStorage persistence
- **Monetization UI**: Frontend design for subscription tiers (Free, Pro, Business) with feature comparison and ad placement options

### Backend Architecture

**Server Framework:**
- Express.js running on Node.js with TypeScript
- HTTP server created with Node's built-in `http` module
- Development mode uses Vite middleware for HMR integration

**API Design:**
- RESTful API endpoints under `/api` prefix
- CRUD operations for bingo cards:
  - `POST /api/cards` - Create new card
  - `GET /api/cards/:id` - Retrieve card by ID
  - `PATCH /api/cards/:id` - Update card (title, tiles, customization)
  - `DELETE /api/cards/:id` - Delete card

**Request Validation:**
- Zod schemas for runtime type validation on API inputs
- Shares schema definitions between client and server via `shared/schema.ts`
- Graceful error handling with appropriate HTTP status codes

**Data Storage Strategy:**
- PostgreSQL database with Drizzle ORM for persistent storage
- Abstracted behind `IStorage` interface with automatic fallback to in-memory storage if DATABASE_URL is unavailable
- Cards stored with UUID identifiers generated by Node's `crypto` module
- Database schema managed via `npm run db:push`

**Production Build:**
- esbuild bundles server code with selective dependency bundling for faster cold starts
- Vite bundles client code with code splitting and optimization
- Static files served from `dist/public` directory
- Single-file CJS output for server at `dist/index.cjs`

### Data Schema

**BingoCard Structure:**
```typescript
{
  id: string (UUID)
  title: string
  tiles: BingoTile[] (array of 25 tiles)
  customization: Customization
}
```

**BingoTile:**
- id (number 0-24)
- text (string)
- completed (boolean)
- completedAt (ISO timestamp or null)
- backgroundImage (base64 data URL or null - set via customization events)

**Customization:**
- boardBackgroundColor (hex color)
- boardBackgroundImage (base64 data URL or null)
- tileBackgroundColor (hex color)
- tileBackgroundImage (base64 data URL or null)
- tileTextColor (hex color)
- tileGlassEffect (boolean for frosted glass tile appearance)
- markerType (enum: circle, star, checkmark, heart)
- markerColor (hex color)
- markerSize (percentage 50-150, default 50% = original 24/32px icons)
- markerImage (base64 data URL for custom marker - only for circle/star/heart, not checkmark)
- deadline (ISO timestamp for board deadline)
- titleColor (hex color, defaults to white for dark mode visibility)
- goalColor (hex color for goal text)
- goalFont (font family for goal text)
- titleAlignment (left, center, right)
- titleFont (font family for title)
- rows (number 2-10, default 5)
- columns (number 2-10, default 5)
- tileSpacing (0-20px, default 8px)
- tileCorners (square or rounded)
